The plugin is now `bg-skills`, a fork of mattpocock/skills, and four skills are renamed to nouns: `to-spec` is `spec-gen`, `to-tickets` is `ticket-gen`, `setup-matt-pocock-skills` is `bg-setup`, and `ask-matt` is `skill-map`. Claude Code installs from this repo's own marketplace (`claude plugin marketplace add Ballganda/BG-skills`, then `claude plugin install bg-skills@bg-skills`) instead of `claude-plugins-official`. Docs live in the repo with relative links; nothing is published to a website.
