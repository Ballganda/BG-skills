The plugin is now `bg-skills`, a fork of mattpocock/skills, and four skills are renamed to nouns: `to-spec` is `spec-gen`, `to-tickets` is `ticket-gen`, `setup-matt-pocock-skills` is `bg-setup`, and `ask-matt` is `skill-map`. Claude Code installs from this repo's own marketplace instead of `claude-plugins-official`: see [Installation](https://github.com/Ballganda/BG-skills#installation-30-second-setup) in the README. Docs live in the repo with relative links; nothing is published to a website.
