`bg-setup` writes a `- Replies:` line into the `## Agent skills` block, a rule that shapes every reply to the user: an "Understood:" line, the outcome in one sentence, then bullets of one fact each, with each offer of further work and each of two or more decisions as a numbered item carrying a recommendation. Repos that are already set up get the rule by re-running `/bg-setup`, which adds the line when it is missing and asks before rewriting an edited one.
