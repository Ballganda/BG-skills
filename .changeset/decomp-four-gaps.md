Decomp skills close four gaps found against a working byte-matching project. The guardrail scan now refuses the forms that hide a directive (trigraphs, backslash line continuations, `%:` digraph directives) and holds `__pragma` and `_Pragma` to the pragma allowlist. `toolchain.json` can accept several target editions, recognise one by probes (hashes of chosen byte ranges), name known-wrong editions with a message, and list the functions an edition holds differently; `check` and `verify` exit 6 on those. Projects gain a symbol map (`symbols.json`), guarded from writers and repaired by `decomp-reference`, and [LAYOUT.md](../skills/engineering/decomp-standards/LAYOUT.md) states a default relocation policy that masks a relocated operand only when its target is proven. Provisioning gains host prerequisites checked by `doctor`, unpack steps that run a project script (`{tools}`), one tool wrapper, and a per-unit compiler (`compiler`, `unit_compilers`, `{compiler}`). `scripts/test-decomp.py` tests `decomp.py` against a scratch project.
