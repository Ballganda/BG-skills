Add nine in-progress `decomp-*` skills for byte-for-byte binary reconstruction: `decomp-setup` (contract and enforcing project, no decomp), `decomp-identify` (compiler and flags from the binary), `decomp-start` with `decomp-spec-gen` and `decomp-ticket-gen` (inventory, unit specs, function tickets), `decomp-run` (separate writer, tool, and auditor roles, automatic proven-lesson capture), `decomp-match` (one function to an exact match), `decomp-reference` (shared declaration repair under a lock, rejected on any regression), and `decomp-standards` (guardrails, size tiers, mismatch categories, layout). `decomp-setup` ships `decomp.py`, the project tool that alone records matches. Existing skills are unchanged.
